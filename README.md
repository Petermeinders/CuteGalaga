# CuteGalaga 👾

A tiny, mobile-first Galaga clone for GitHub Pages. Touch-friendly
controls, portrait play, no build step — pure static HTML/CSS/JS.

## Prototype

- **Ship builder** screen (Wings / Core / Blaster reels + SPIN! + PLAY)
- Portrait solo + landscape **Coop**
- **Autofire**, **Cute** (confetti + sounds + bug sprites), **Slow-mo**
- Candy bunkers, waves, score, lives
- **Pulse Orb** core: expanding nova rings, bullet wipe, bunker break
- Enemy variety (wasp, moth, beetle, firefly, sniper) with distinct behaviors
- Power-up drops: ⚡ rapid, 🔱 spread, 💣 explosive, ➕ weapon upgrade, 🛡️ shield, ❤️ life

## Local dev

```
python -m http.server 8080
```

then open `http://localhost:8080`.

## Deploy

Push to GitHub and enable Pages on the `main` branch root — nothing else
required.
